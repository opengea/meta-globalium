# The 80 canonical categories

The 80 categories are the **canonical instantiation** of the Meta-Globàlium — the consolidated ontological vocabulary the model proposes for human reality.

They emerge from the 8 root categories (see [`8-root-categories.md`](8-root-categories.md)) by application of the **fourth radial axis** (PLA / Neutral / MON), generating layered expressions for each cardinal direction.

| Layer | Type | Count | Geometry |
|-------|------|-------|----------|
| Plasmatic | atemporal/foundational | 27 | inner sphere, radius 0–50 |
| Neutral | mediator/axial | 26 | mediator sphere, radius 60–80 |
| Mundane | temporal/phenomenal | 30 | outer sphere, radius 100–155 |
| **Total** | | **83** | |

> Polar construction vertices (single-letter labels at radius 233) are excluded from this listing — they are scaffolding for the 3D projection, not canonical categories. They are present in the JSON export with `coords_3d` magnitude 233.
